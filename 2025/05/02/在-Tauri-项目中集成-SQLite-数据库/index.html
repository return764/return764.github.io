使用 tauri-plugin-sqlite 在 Tauri 项目中集成 SQLite 数据库

随着 Tauri 框架的逐渐成熟，越来越多开发者开始使用它来开发跨平台桌面应用。
本文将介绍如何使用 tauri-plugin-sqlite 在 Tauri 项目中集成 SQLite 数据库功能。

📦 插件简介

tauri-plugin-sqlite 是一个基于官方 SQLite 插件魔改而来的 Tauri 插件，支持：

  • 基于 SQLite 的轻量级数据库操作
  • 使用 Rust 实现的后端数据库访问
  • 与前端（如 Vue/React/Svelte）无缝通信

该插件适用于想在 Tauri 桌面应用中引入本地数据库功能的场景，尤其是小型应用或离线数据存储。

💡 注意事项

  • 使用 sqlite:<name>.db 格式指定数据库文件名
  • 插件提供了 execute、select 等方法，分别对应执行和查询 SQL 语句
  • 插件本身不提供 ORM，需手动编写 SQL 语句

✅ 总结

本插件仅仅是官方的tauri-plugin-sql插件的sqlite的导出版，移除了对Mysql和Postgres的支持，同时添加了对sqlite的extension的支持，这是官方库无法做到的

tauri-plugin-sqlite 是一个轻量、易用的 Tauri 插件，适合在桌面应用中使用 SQLite 存储数据。如果你正打算构建一个本地存储驱动的桌面应用，不妨一试。
