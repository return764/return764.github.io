为什么选择 Hexo + GitHub Pages

Hexo 是一个静态博客生成器：我们在本地编写 Markdown，Hexo 负责把文章、主题模板和资源文件生成成静态 HTML、CSS、JavaScript。GitHub Pages 则负责托管这些静态文件，让博客可以通过 https://<username>.github.io/ 访问。

这套组合的优点很直接：

  • 内容使用 Markdown 管理，写作和版本控制都很自然
  • 生成结果是静态文件，访问速度快，也不需要维护服务器
  • 可以直接用 GitHub 仓库托管和发布

常见问题

页面样式丢失

优先检查 _config.yml 里的 url 是否正确。如果是项目站点，还要检查 root 是否包含项目路径。

部署成功但页面没更新

可以检查三个地方：

  • GitHub Pages 设置里的发布分支是否正确
  • hexo deploy 推送到的分支是否和 Pages 分支一致
  • 浏览器或 CDN 是否缓存了旧页面

认证失败

如果使用 SSH，检查本机 SSH key 是否已经添加到 GitHub。如果使用 HTTPS，确认 token 或凭据是否可用。
